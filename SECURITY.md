# Segurança

## Para quem instala

1. Inspecione o `SKILL.md`, os arquivos de apoio e a licença antes de instalar.
2. Instale uma versão imutável, por tag ou commit, não pelo branch `main`.
3. Não execute scripts da skill só porque ela foi instalada.
4. Nunca cole tokens, senhas, client secrets, códigos OAuth, URLs de callback OAuth ou arquivos `.env` em chats, tickets ou documentos públicos.

## Para quem contribui

Não publique credenciais, dados de alunos, dados de clientes, contatos, logs reais, arquivos `.env`, tokens OAuth ou chaves privadas.

Reporte uma falha de segurança de forma privada pela aba **Security** deste repositório (*Report a vulnerability*).
Vale para as skills, o site agentsflix.ai, as funções em `/api` e o player em `/assistir`. Não abra issue pública
com material sensível.
