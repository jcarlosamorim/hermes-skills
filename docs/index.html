Cada obra deste catálogo é uma skill do Hermes Agent: um procedimento com verificação, escrito para ser instalado por um comando. Copy, lançamento, processos, o Hybrid Workspace do seu negócio, tráfego. Clique, copie, cole no seu Hermes. Código aberto, licença MIT, escaneado pelo mesmo scanner que o Hermes usa.

Dois jeitos de instalar. tap add lê o branch main e serve para descobrir e atualizar (hermes skills update). O comando de cada card usa a URL presa numa tag: é o que dá aula reproduzível, porque todo mundo instala exatamente o mesmo arquivo.
Antes de instalar, o Hermes inspeciona e escaneia a skill. Este hub é community por definição do Hermes: qualquer achado high ou critical bloqueia a instalação, e o CI deste repositório reprova o build antes disso. Fonte: github.com/jcarlosamorim/hermes-skills
